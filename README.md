# FurRIT

This repository contains source code for the website for the Furries of
Rochester Institute of Technology, known as FurRIT. A live of this site is
hosted at [furrit.us](https://furrit.us). The source code is hosted on
[GitHub](https://github.com/FurRIT/site) - which is where you're probably
viewing this.

## History

This project is a reimplementation of FurRIT's existing website rebuilt using
modern tooling and conventions.
